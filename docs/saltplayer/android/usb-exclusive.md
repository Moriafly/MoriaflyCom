# USB 独占模式

USB 独占模式（USB DAC 独占 / USB Audio 独占）是椒盐音乐 Android 版为外接 USB 解码器（DAC / 小尾巴）提供的一项高阶音频输出功能。开启后，播放器将绕过 Android 系统默认的音频重采样与混音，直接向 USB DAC 输出原始音频数据，从而有效降低延迟、减少音质损失，充分发挥外接解码设备的性能。

## 适用场景

- 使用 USB-C 转 3.5mm 小尾巴、便携解码耳放或桌面 DAC 听音乐
- 对音质有较高要求，希望避免 Android SRC（采样率转换）带来的劣化
- 播放高解析度音频（Hi-Res）时，希望 DAC 以原生采样率接收数据

## 支持平台

- **Android**：支持 Android 5.0 及以上设备，具体效果受系统音频架构与 DAC 兼容性影响
- **HarmonyOS / Windows / macOS / Linux**：不适用或采用其他音频输出机制

## 如何开启

1. 将 USB DAC 通过 OTG 线或 USB-C 线缆连接到手机
2. 打开椒盐音乐，进入**设置 → 音频输出 → USB 独占模式**
3. 开启 **USB 独占模式** 开关
4. （可选）根据需要选择**固定采样率**、**位深**等高级选项

## 常见问题

### 开启后没有声音

- 确认 DAC 已被系统识别，且椒盐音乐具有 USB 设备访问权限
- 部分 DAC 需要配合专用驱动或仅在特定采样率下工作，尝试调整输出参数
- 某些系统会强制占用 USB 音频设备，导致独占失败，可尝试关闭其他音频应用

### 独占模式自动断开

- 来电、通知、语音助手或其他应用请求音频焦点时，系统可能中断独占输出
- 部分厂商系统会对后台 USB 访问进行限制，建议在电池优化中将椒盐音乐设为允许后台运行

### 底噪或爆音

- 检查 USB 线材与接口接触是否良好
- 尝试调整缓冲区大小（Buffer Size），较大的缓冲区通常更稳定
- 某些 DAC 对特定的采样率或位深支持不佳，可尝试锁定常用参数

## 注意事项

- USB 独占模式下，系统音量调节可能失效，需通过 DAC 上的物理旋钮控制音量
- 独占输出会占用 USB 音频设备，其他应用在此期间通常无法播放声音
- 若遇到兼容性问题，可临时关闭独占模式，使用 Android 标准音频输出
