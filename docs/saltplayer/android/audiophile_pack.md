# Audiophile Pack

Audiophile Pack 是 Salt Player 12.1.0 版本推出的拓展包。

## USB 独占模式

### 兼容性

USB 独占模式：为真实 DAC 而生的全链路兼容方案

自 12.0.0 版本起，Salt Player 围绕 USB 独占模式进行了超过 120 次专项迭代，从“让 DAC 出声”演进为“让每一款 DAC 都能稳定、低延迟、高保真地出声”。我们的目标不是参数堆叠，而是基于真实设备、真实协议与真实音源信息的实时适配。

兼容性，是我们最厚重的 engineering 投入。我们针对 HiBy W4、iBasso DC03 Pro / DC04 Pro / DC04U、FiiO KA13、JieLi 方案以及大量采用 CS43131 芯片的 DAC 做了深度设备级适配。面对 UAC1 / UAC2 不同协议、clock 源不稳定、采样率锁定失败等复杂场景，系统会智能回退到端点级采样率设置；异步 DAC支持反馈时钟精确同步，自适应同步端点配合格式切换预静音机制，有效消除切歌爆音。源文件的位深与采样率由播放内核实时解析并校准后再协商输出，避免依赖错误元数据导致的误转码，让最终进入 DAC 的数据尽可能“原汁原味”。

音质与性能，同样走到了原生层深处。USB 独占模式采用原生等时传输，并加入播放/暂停淡入淡出；前后台可独立调节传输缓冲，在低延迟与后台抗抖动之间自由取舍，动态传输单元计算进一步提升了后台稳定性。支持 DAC 硬件音量（AUTO / HARDWARE / SOFTWARE） 并在模式切换时平滑交接；提供原始数字电平直出模式，以及 TPDF 抖动 优化高位深转 16-bit的量化质量；结合全新播放引擎，独占模式下也能体验无间隙播放（Gapless）。

问题可被追踪，体验可被保障。内置实时传输统计与诊断面板，完整收集失败原因并生成反馈报告；USB DAC Badge 实时指示独占状态，未进入独占时主动提醒用户。针对小米 / OPPO 等系统的电池策略、USB 权限缺失、USB Host 能力检测，也都做了前置引导，减少无效排查。

如果你追求 Android + USB DAC 的极致还原，Salt Player 的 USB 独占模式已经为此准就绪。
